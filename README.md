# ALAA Portfolio (Next.js + Tailwind)
1. `npm install`
2. Copy `.env.example` to `.env.local` and set your domain
3. Videos: `public/videos/` (work-1.mp4, work-3.mp4). Thumbnails: `public/thumbs/` then set `thumb` in `data/content.js`
4. `npm run dev`  /  `npm run build && npm start`

Hero height = 100svh - navbar height. Navbar height is the CSS var `--nav-h` in `app/globals.css`.
